FutureFunds Desktop/Mobile Mockup

A responsive UI mockup for a financial guidance company; audience is everyday users seeking budgeting and investment help. Needed to show the same core actions (budget planning, calculator, booking) working cleanly across both desktop and mobile without losing hierarchy.

Concept uses a calm mint-and-green palette to make finance feel approachable rather than intimidating, with icon-labeled service cards (budgeting, debt, investing) giving users an instant menu of what the company offers. The mobile version stacks the same modules vertically in priority order — hero, calculator, booking, blog, testimonials — proving the layout was designed responsively, not just shrunk down.

Best demonstration of responsive design thinking — showing the same information architecture adapted correctly across two breakpoints is a core UI/UX skill that single static pieces can't show.
